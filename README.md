# Grab your Key

Circle of Fifths App to display scales and chords of a selected key. Random chord progression for daily practising.
Inspired by the video [Practice THIS Every Day](https://scottsbasslessons.com/blog/practice-this-every-day) by Scott
Devine.

## Getting started

```
npm install
npm run dev
```

The dev server is also reachable in the local network (see the `Network` URL in the console).

## Deploy

```
npm run deploy
```

Builds the app and copies `dist` via scp to `/home/mettbox/public/gyk.mettbox.de` on the SSH host
`uberspace`.
